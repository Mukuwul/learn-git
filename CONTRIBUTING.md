# Contributing

This repo is a playground for practicing Git and GitHub workflows.

## Workflow

1. Create a branch: `git checkout -b my-change`
2. Commit your work: `git commit -m "Describe the change"`
3. Push it: `git push -u origin my-change`
4. Open a pull request and merge it into `main`.

## Pairing

When two people work on the same change, credit both by adding a
trailer to the commit message, after a blank line:

```
Co-authored-by: username <ID+username@users.noreply.github.com>
```
